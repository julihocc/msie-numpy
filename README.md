# Ejemplos de NumPy y métodos numéricos

Ejemplos de NumPy y de métodos numéricos con Python: ocho ejemplos de NumPy, el método de bisección y la búsqueda de raíces con SciPy. Incluye dos cuadernos de prueba y dos programas mínimos.

**Dirigido a:** Estudiantes que quieren ver ejemplos sencillos de NumPy y de métodos numéricos con Python.

## Contenido

| Elemento | Descripción |
|---|---|
| `numpy/example-01.py … example-08.py` | Ocho ejemplos de NumPy. |
| `numpy/biseccion.py` | Método de bisección con gráfica (Matplotlib). |
| `numpy/finding_roots.py` | Búsqueda de raíces con `scipy.optimize.root`. |
| `hola-mundo.py y suma.py` | Programas mínimos de prueba. |
| `example.ipynb y mi-libreta.ipynb` | Cuadernos de prueba (una celda de código cada uno). |
| `mi-libreta.html` | Exportación a HTML del cuaderno `mi-libreta.ipynb`. |

## Cómo usar este material

1. Instala las bibliotecas: `pip install numpy matplotlib scipy`.
2. Ejecuta un ejemplo con `python numpy/example-01.py`.
